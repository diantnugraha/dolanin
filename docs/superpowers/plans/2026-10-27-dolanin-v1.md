# Dolanin v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun web katalog akomodasi Dolanin (halaman publik mobile-first, CMS satu admin, pencatatan klik, dan dashboard) dalam satu aplikasi Next.js, sesuai dokumen desain yang sudah disetujui.

**Architecture:** Satu aplikasi Next.js App Router di Vercel. Halaman publik dirender dinamis di server dan membaca Postgres lewat Prisma. CMS ada di `/admin` dan dilindungi sesi cookie bertanda tangan HMAC. Foto diunggah langsung dari browser ke S3 (lewat presigned URL), lalu dikirim lewat CloudFront. Video diunggah langsung ke Bunny Stream (TUS), dan status encoding-nya diterima lewat webhook. Klik Pesan/WA melewati rute `/go/...` yang mencatat event lalu mengalihkan (302). Kunjungan halaman detail dicatat lewat beacon.

**Tech Stack:**
- Next.js 16 (App Router, TypeScript), CSS Modules + token CSS global (tanpa Tailwind)
- Prisma 7 stabil (7.10.x, **bukan** tag `latest` 8.0 RC) + `@prisma/adapter-pg` + PostgreSQL
- zod, `@tabler/icons-react`, `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner`, `tus-js-client`
- Vitest untuk unit dan integrasi, Playwright untuk E2E

**Spec:** `docs/superpowers/specs/2026-10-26-dolanin-design.md`. Baca bersama `PRODUCT.md` dan mockup di `docs/superpowers/specs/2026-10-26-dolanin-mockups/`. Semua tampilan **di-port dari mockup**, jadi buka file mockup yang disebut di tiap task.

## Global Constraints

- Bahasa UI: Indonesia, nada santai ("kamu"/"-mu"). Jangan pakai frasa "sudah kami pilihkan". Jangan mengarang rating, testimoni, statistik, atau klaim "termurah"/"terpercaya".
- Tagline persis: "Yuk, dolan! Nginepnya biar **hemat**, jalan‑jalannya puas." Pakai tanda hubung tak-putus U+2011 di "jalan‑jalannya", dan kata "hemat" diberi `<mark>` Kuning senja.
- Subline persis: "Bandingkan hotel, penginapan, dan villa murah per kota, lalu pesan lewat link resmi atau tanya via WhatsApp."
- Token warna:
  - Jingga `#F26B3A`, Biru laut `#0E8C8C`, Kuning senja `#FFC24B`, Malam `#1F2A37`, Pasir `#FFF6EC`
  - Tint `#FFEFE8` / `#E3F4F4`, WA `#25D366`, abu `#6B7280`
  - Teks sekunder di atas Pasir `#575E6B`
  - Warna tautan/teks Biru laut di atas latar terang `#0A6B6B`
- Font: Poppins 400/500/600/700 lewat `next/font/google`. Kartu radius 16px, tombol pill, ikon Tabler outline, spasi kelipatan 4px.
- **Dilarang:** gradient (termasuk scrim di atas foto, jadi pakai panel solid), glass/blur dekoratif, emoji sebagai ikon, eyebrow di atas judul.
- Tombol jingga memakai teks dan ikon Malam `#1F2A37`, bukan putih.
- Teks minimal 11px. Harga jingga minimal 20px/700. Fokus keyboard memakai outline 2px Biru laut.
- Mobile-first: setiap halaman publik dicek di lebar 390px dan 1280px. Tema terang saja. CMS dioptimalkan untuk laptop, tapi di 390px tidak boleh ada scroll horizontal halaman (tabel boleh scroll di dalam wadahnya sendiri).
- Batas desain:
  - Hanya tipe `HOTEL | PENGINAPAN | VILLA`.
  - Satu akun admin, tanpa role.
  - Tidak ada booking/pembayaran, rating, akun pengunjung, impor massal, maupun embed IG/TikTok.
- Keamanan:
  - URL yang disimpan admin (link affiliate, link Maps) hanya boleh `http:`/`https:`.
  - Semua server action dan route admin memanggil `requireAdmin()`.
  - Event tidak menyimpan IP atau data pribadi.
- Upload media tidak pernah lewat function Vercel (batas 4,5 MB). Upload selalu langsung dari browser ke S3/Bunny.
- Zona waktu statistik: `Asia/Jakarta` (WIB).
- Setelah mengubah kode di setiap task, jalankan `graphify update .` (aturan CLAUDE.md).
- Perintah tes:
  - `npm run test:unit`: Vitest `tests/unit`
  - `npm run test:int`: Vitest `tests/int`, memakai `DATABASE_URL` dari `.env.test`
  - `npm run test:e2e`: Playwright `tests/e2e`

## Review Focus

1. **Harga diketik dengan titik ribuan** ("185.000", "Rp 185.000", "185.000,00"). Harus tersimpan 185000, bukan 185 atau error. Tes ada di Task 1.
2. **Nomor WA format lokal** ("0812-3456-7890", "+62 812 3456 7890", "812 3456 7890"). Harus dinormalisasi ke `62…`. Nomor rumah atau sampah ditolak dengan pesan. Listing tanpa nomor sendiri dan tanpa nomor default: tombol WA disembunyikan dan `/go/{id}/wa` mengembalikan 404. Tes ada di Task 3 dan Task 9.
3. **Slug kota bentrok dengan rute** (`kota`, `promo`, `cari`, `admin`, `go`, `api`) atau kembar. Harus ditolak saat menyimpan kota. Tes ada di Task 14.
4. **Video belum siap atau gagal encode**, atau listing yang medianya hanya video belum siap. Halaman publik tidak boleh menampilkan player rusak, cover jatuh ke foto pertama atau placeholder. Tes ada di Task 4.
5. **Dashboard tanpa data, kunjungan 0, atau periode sebelumnya 0.** Tidak boleh muncul NaN/Infinity: rasio tampil "–" dan pil delta disembunyikan. Event pukul 00:30 WIB dihitung di tanggal WIB-nya, bukan tanggal UTC. Tes ada di Task 15.
